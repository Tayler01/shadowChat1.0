# Original book binding atlas

Created with the built-in image generation tool on September 13, 2026. Project asset: `Assets/Resources/Textures/BookSpines.png`. Original generated file is retained in the Codex generated-images folder. The asset is applied to actual 3D book spine geometry; it is not a rendered room backdrop.

## Prompt

Create a production 3D game texture atlas: a precise straight-on orthographic photographic scan of EIGHT different antique leather book SPINES arranged side by side as eight equal-width vertical strips, each strip from very top to very bottom, no gap. Canvas landscape 2:1 ratio, ideally 2048x1024. Each spine occupies exactly 1/8 of image width. All book spines same rectangular outer dimensions, varied authentic aged burgundy, umber, near-black walnut, tobacco and dark forest-green leather. Elaborate but subtle worn gilt tooling, floral filigree, raised horizontal binding bands, tiny embossed historic celestial and heraldic motifs, scuffed corners, fine leather pores and hairline cracks. Reference mood: an exquisite candlelit Renaissance scholar's study, yet THIS IMAGE IS ONLY A NEUTRALLY LIT DIFFUSE MATERIAL SCAN, no directional lighting, no highlights, no cast shadows, no room, no table, no hands, no books seen at angle, no perspective, no borders, no mockup, no writing or legible lettering. Photorealistic historic leather and aged gold tooling with tangible microdetail, premium game material. Make the base colors medium-dark enough to receive warm lighting in Unity, avoid crushed blacks. Rectilinear texture edges suitable for mapping directly onto actual 3D rectangular book spines.
